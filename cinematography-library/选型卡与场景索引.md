# 选型卡与场景索引

版本 0.2，2026-09-20。机制依据见[主库](摄影参数与视觉机制库.md)，视觉依据见[官方对照案例](官方对照案例.md)。以下数值是条件明确的**本库测试建议**，不是原图还原值，也不是官方审美配方；均未完成实拍或模型验证。

## 先把场景词转成可观察的需求

| 用户输入 | 从图中先检查 | 进入哪张卡 |
| --- | --- | --- |
| 夏日树荫 | 发丝受光、面部暗侧、白衣纹理、环境可辨程度、局部泛光 | P01、P03、P07 |
| 旅游赏樱 | 地点是否重要；花是环境、前景还是画面主体 | P01 或 P02，再看 P03 |
| 安静室内 | 窗光方向、脸部暗侧、背景是否需要交代 | P04 |
| 奔跑、运动 | 是否需要辨认动作瞬间；是否需要慢放 | P05 |
| 梦境、时间流逝 | 拖影发生在哪个对象，主体是否必须清楚 | P06 |
| 胶片感 | 需要真实胶片拍摄还是数字外观；颗粒、反差和色彩各是什么目标 | P08 |

同一场景可以选不同方案。题材词只负责找到待检查的问题。

## P01 人物与环境都要被看见

**适用**：旅行、树荫、街道和建筑中的人物；地点是内容的一部分。关联 L01、D02；案例 V01、V02。

**先定关系**：明确人物全身／半身占比，并保留至少一个地点锚点。先选机位，再用视角完成取景。

**测试起点**：在有效记录宽度约 36mm、球面镜头且无额外水平裁切的条件下，试 35mm 与 50mm。站位不变先看环境范围差异；需要同样人物大小时再调整距离，并记录透视随之改变。景深可从 f/4 与 f/5.6 比较，记录对焦距离及背景距离，不预先承诺背景清晰。

**结果不对先改什么**：背景信息不够，先检查构图与人物占比；背景已入画但太虚，再检查距离关系与光圈。近处手脚显得过大，先退开机位。

**正文只写**：人物清楚，树干、栏杆与后方墙面的关系仍可辨，环境保留自然层次。

## P02 花枝包围人物，前景明显柔化

**适用**：赏樱、花园、隔叶人像。关联 L02、D01；案例 V01、V02。

**先定关系**：花枝靠近镜头、人物在中景，背景与人物拉开距离；保留眼睛与表情的观看通道。

**测试起点**：同 P01 的记录画幅条件，有足够退距时试 85mm、f/2.8 与 f/4。先调整前景花枝距离，再判断是否需要更大光圈；窄路无法后退时，改用较短焦距重新组织前景，不硬塞长焦方案。

**结果不对先改什么**：花糊住脸，先移动花枝或机位；整片背景成为无意义色块，增加可读层次；想保留地点时返回 P01。长焦距本身不保证所有背景都虚化。

**正文只写**：近处花瓣柔化成疏密不一的前景，中景面部清楚，后方花枝仍保留形态。

## P03 明亮侧逆光，暗侧柔和，局部泛光

**适用**：参考夏日图的受光关系，以及日光下的花园人物。关联 G01、G02、E01、O01、O02；案例 V03、V04、V06。

**先定关系**：侧后方强光照到发丝、肩部或花瓣，面部由天空和周围反射光照明；泛光主要出现在强光一侧。

**测试顺序**：先拍无扩散滤镜基准，改变光源与镜头夹角并控制遮光，判断是否已有需要的局部泛光。脸部过暗先调站位或补光；确实还缺亮部扩散时，再试同系列低强度滤镜，例如 Black Pro-Mist 无滤镜／1/8／1/4。此组强度是测试梯度，不是对参考图的判定。

**结果不对先改什么**：白衣关键纹理消失，检查记录曝光与光线反差；全画面发白，检查杂散光与滤镜；面部太平，降低补光或调整方向。不要同时加入浓雾、强扩散和大面积后期辉光。

**正文只写**：侧逆光照亮发丝与白衣边缘，面部暗侧柔和可读；强光一侧局部泛光，其余区域保留层次。

## P04 柔光中的安静与深暗

**适用**：窗边人物、室内静物、需要暗部包围的场景。关联 G01、G02、E01；案例 V03、V04。

**先定关系**：较大的侧向光源形成柔和阴影边缘；控制房间反射及补光量，保留暗侧。背景照明是否加入由空间信息决定。

**测试起点**：固定主光、曝光与显示转换，比较无额外补光、白板反射、减少反射三种状态。逐项改变，观察暗侧可读性与立体感。这里不预填“4:1”，因为未说明它是光源照度比还是面部亮暗比。

**正文只写**：侧窗光在面部缓缓过渡，背光侧保留深度，后方空间仅露出必要结构。

## P05 正常时间中的清脆动作，或慢放细节

**适用**：风吹衣摆、奔跑、触水等需要明确运动表现的镜头。关联 T01、T02、T04；资料 V05。

**测试起点**：假设交付为 25fps。正常时间比较 25fps／180°（1/50秒）与 25fps／90°（1/100秒）；后者单帧入光少一挡，需要独立补偿。需要半速时另选 50fps／180°，逐帧按 25fps 播放。现场灯光与设备能力须另行验证。

**结果不对先改什么**：动作断续，先看曝光时间与像移速度；运动太慢，检查回放倍率和表演，不靠修改光圈解决。

**正文二选一**：正常速度，动作轮廓清楚、运动短促；或仅水滴细节半速，其余保持正常时间。不把两套要求同时套给全片。

## P06 有意保留拖影

**适用**：运动色带、主观恍惚或时间延展。关联 T03；资料 V05。

**测试起点**：假设交付为 25fps，固定摄影机，试 180°与270°（约1/33.3秒），固定主体运动速度并补偿亮度。270°比180°增加约0.585挡入光。

**条件**：若主要人物需要清楚，应使人物在曝光期间相对画面少移动，同时让指定前景运动。相机一旦移动，各层像移都要重新检查。

**正文只写**：固定视点，掠过的近处枝叶带方向性拖影，人物保持短暂停留。

## P07 曝光服务于白衣、肤色和暗部

**适用**：大面积白衣、强逆光或窗内外反差。关联 E01、E02、C01。

**先定优先级**：指定必须保留纹理的白衣区域、必须可读的面部暗侧，以及可接受失去细节的亮点。不能写“所有高光绝不过曝”又要求强光自由溢出。

**测试起点**：固定运动所需快门与景深所需光圈，使用该相机已确认的监看转换，以曝光工具检查关键区域。若整体入光过多，可用 ND；若只是明暗反差过大，调整光线或补光，单独加 ND 不会缩小场景光比。具体 ISO／EI、阈值按设备测试确定。

**结果不对先改什么**：先区分素材已剪切还是显示转换压缩了细节，再处理。不要用提高最终画面亮度替代记录曝光检查。

**正文只写**：白衣受光区保留主要褶皱，肤色明亮，树荫和深色衣料仍有层次。

## P08 胶片及完成质感

真实胶片拍摄先按感光需求、光源与流程选产品；AI提示词则先选可见质感。下表是产品条件入口，尚未完成统一曝光、冲洗与扫描条件下的横向样片比较。

| 候选 | 有依据的选择条件 | 仍需决定 |
| --- | --- | --- |
| [Kodak VISION3 50D](https://www.kodak.com/en/motion/product/camera-films/50d-5203-7203/) | 日光型低感光度负片；光量充足、重视细腻颗粒时列入候选 | 规格、所需光圈／速度、实际测光与扫描 |
| [Kodak VISION3 250D](https://www.kodak.com/en/motion/product/camera-films/250d-5207-7207/) | 日光型负片；相较50D需要更多感光余量时列入候选 | 阴影曝光、光量变化和后期目标 |
| [Kodak VISION3 500T](https://www.kodak.com/en/motion/product/camera-films/500t-5219-7219/) | 钨丝灯型高感光度负片；有限光量条件下列入候选 | 混合光／日光下色彩平衡处理、颗粒与曝光测试 |
| [Kodak VISION Color Print 2383](https://www.kodak.com/en/motion/product/post/print-films/vision-color-2383-3383/) | 印片环节参考 | 实际印片或数字模拟流程；不能作为拍摄负片填写 |

**AI质感选择表**：颗粒要细还是明显；黑位扎实还是稍抬；高光边缘干净还是轻微扩散；色彩克制还是饱满；哪些材质仍需清楚。按参考选择，不默认五项都加强。

**正文只写所选结果**：例如“轻微细颗粒，白衣亮部过渡柔和，浓绿与肤色保持区分”。只有型号比这句话多提供了必要信息时，才加入片名。

## 输出时，哪里概括，哪里展开

| 六段职责 | 概括到什么程度 | 值得具体写的内容 |
| --- | --- | --- |
| 整体定位 | 场景＋成像类型＋两三个质感词 | 决定主题的一两种空间关系；不提前写完整动作 |
| 成像 | 最终亮暗、肤色与材质目标 | 该题材真正困难的亮暗信息；有依据才写系统与色彩流程 |
| 镜头分工 | 空间、人物、细节各自职责 | 画幅明确后的焦段与用途；不列无用的完整镜头组 |
| 景深 | 前中后层分别多清楚 | 容易冲突的清晰对象、距离条件；必要时写光圈候选 |
| 时间 | 常速基准 | 只有确需特殊效果的镜头写慢放或快门例外；纯图片任务可省 |
| 光学 | 需要的扩散或泛光程度 | 效果出现的位置、要保留的细节；型号和强度须有选型依据 |

内部分析可以详细；最终每段只承担一个职责。灯位、道具结构、完整表演等细节进入相应章节，不因知识库变大就写进通用质感段。
