# 动作、视点与镜头组织

接收主体意图、空间节点和成像规则；独立使用时直接从当前请求提取。完整故事交付有行动与衔接的镜头段落，不只给抽象语法。未给片长用无秒数的段落；用户要求精确总长而未给目标时先澄清。纯摄影或单张图片任务不展开时间线。

## 设计

1. **人物目的与动作链**：沿空间路线写“地点 → 起始状态 → 有动机的主动作 → 结束状态 → 下一段衔接”。动作引发发现、选择或情绪变化，不以同一姿态换景别代替故事。微动作由情境触发，不机械插入撩发、浅笑、回眸。
2. **观看视点**：第三人称交代位置与行为；人物第一人称呈现其所见；过肩仍含人物，不冒充纯主观镜头。主观切入由视线、接触动作或空间关系建立，返回承接反应或动作。核对视点归属、眼高、目标方位与出入方向，不为凑比例交替。
3. **摄影机任务**：推进靠近信息，侧移揭示遮挡，跟随保持移动关系，固定机位让动作或环境发生变化。具体运动写起点、过程与落点；每镜突出主要动作和主要运动，复杂行动允许必要动作链。
4. **节奏**：分别安排人物、环境、摄影机和剪辑速度。安静不等于全片慢放，紧张不等于持续晃动。慢放和拖影继承摄影模块的成像规则，不另设冲突参数。
5. **衔接与状态**：关键道具、手部接触、脚步支撑、视线与门窗状态可追踪。空镜承担空间、动作结果或转场任务；身体／反射细节不等于无人空镜。跳切和时空变化按故事目的设计，无需一律顺接。
6. **声音**：用户要求声画方案时按距离与来源绑定声音；音乐、对白、字幕以本次要求为准，不继承其他案例禁项。未请求时不额外增加声音章节。

## 交付与验证

全版把完整行动线与视点衔接放入构图运镜章，人物章补表演和造型，不复写同一动作清单。用户要求分镜表时再按需要列镜号、地点、动作起止、机位、衔接及时间。每镜继承共同参数，不重复整组摄影正文。

精确剪辑检查总帧数和每镜时长；比例注明按镜头数还是时长。换算及特殊拖影条件按需读[技术核对](../cinematic-look-design/references/technical-checks.md)。核对动作时间可行、主要信息可见、视点转换成立、状态连续，修复本次设计而不静默改变用户情节或时长。

内部 `motion_card` 只传递行动线、观看关系、运动节奏和状态锚点。正文交付定案，未验证的合成或拍摄能力不写成保证；只说明影响使用的实际限制。
