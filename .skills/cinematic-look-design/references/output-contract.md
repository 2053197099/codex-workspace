# 通用画面质感段：内容分工与详略

用于“通用画面质感与电影摄影参数”及同类全组摄影提示词。目标是输出能迁移到多个镜头的成像规则；不是单镜头分镜，也不是现场摄影操作手册。

## 六项职责

| 职责 | 必须回答 | 详略边界 |
| --- | --- | --- |
| 整体定位 | 什么场景、什么影像类型、什么完成质感？ | 概括写，最多补一两种决定主题的空间关系；不锁定人物动作和镜头先后。“TVC”等定位仅在符合目标时使用。 |
| 成像 | 高光、暗部、肤色、材质与综合色彩如何呈现？ | 写决定风格的关系；系统和色彩流程有作用才保留。流程名不能替代完成画面目标，不逐件罗列“头发、木柱都有细节”。 |
| 镜头分工 | 各类视角分别拍什么，系列如何保持一致？ | 写焦段组与景别用途，数量随场景需要决定；不凑齐厂商目录，不机械限制为三支镜头。 |
| 景深与透视 | 前、中、后层分别清楚到什么程度？ | 独立说明清晰层级、适用光圈范围及关键比例关系；不让毫米数和T值代替视觉结果。 |
| 时间成像 | 常速、运动模糊与特殊回放如何统一？ | 写基准及确有需要的例外，运镜只写总体速度与稳定性。纯图片任务省略；不编造触水、落花或转角后的镜头顺序。 |
| 光学质感 | 柔化作用在哪些区域，强度与细节边界是什么？ | 具体写效果对象与需保留的信息。只在过度扩散等确切风险存在时写针对性边界，不追加通用禁令清单。 |

六项是责任检查，不是必须凑满的格式。涉及的职责不能在压缩时丢失；内容合并后仍须各自清楚。用户单独要光影时直接展开光影，不先套整段模板。

## 保留什么，移走什么

- **保留风格差异**：如“扎实黑位与浓郁中间调”“前景明显柔化、后景建筑仍可辨”“仅亮部边缘扩散”。这些会改变图像。
- **保留必要边界**：扩散强调柔润时，同时说明暗部不被光雾冲淡，属于防止风格失控，不因是限制句就删除。
- **将基础检查留在内部**：固定白平衡、用ND调曝光、检查镜头覆盖等。用户要实拍执行方案时才展开；明确的冷暖设计或必要技术前提仍应保留。
- **将具体分镜移到下游**：“转过廊角后停留”“先触水再回眸”属于镜头设计。“低速移动，保持自然视差”属于可跨镜头使用的摄影规则。
- **光影与色彩按范围展开**：本段只容纳决定成像的光线性质与综合色彩；完整灯位、色彩面积、逐物体受光进入专门章节。用户只要本段时不擅自追加章节。

## 明确不等于固定单值

“环境人物T2.8至T4、建筑全景T4至T5.6”是适用对象明确的工作范围，不是模棱两可。单镜头条件确定时再收敛数值；不为显得果断而把焦距、光圈、景别捆成唯一配方。

“采用某系列作为成像参考”明确表达选择；“测试候选”尚未完成选择。两者不同。参数不是原图的已知事实，也不能仅凭名称保证生成效果。

## 交付前复核

1. 哪些句子在决定风格，哪些只是在描述基本合格？后者无特殊必要就移走。
2. 删除后会不会丢失独立职责或效果边界？会则保留，不按字数盲删。
3. 每类焦段和光圈范围是否有适用对象？是否与清晰层级一致？
4. 是否混入人物表演、镜头先后或现场排错？按交付范围移走。
5. 品牌与参数是否完成适配审核？最后交付的是已选方案，而非器材菜单。

追求每句有信息增量，不追求最短篇幅，也不反复替换“温润、清透、柔和”等词制造伪细节。
