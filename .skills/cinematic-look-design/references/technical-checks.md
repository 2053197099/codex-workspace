# 摄影参考的技术核对

按需读取。以下公式用于文本校对；并不证明某个生成模型支持对应参数。

## 时间与运动

曝光秒数 = 快门角 ÷ 360 ÷ 拍摄帧率。

| 拍摄设置 | 曝光时间 |
| --- | --- |
| 25fps，180° | 1/50 秒 |
| 50fps，180° | 1/100 秒 |
| 25fps，270° | 0.03 秒，约 1/33.3 秒 |
| 25fps，300° | 1/30 秒 |
| 25fps，360° | 1/25 秒 |

50fps 素材按 25fps 逐帧回放才是半速；只写 50fps 不自动意味着慢动作。

严格剪辑使用整帧：25fps 下 3 帧是 0.12 秒，4 帧是 0.16 秒，8 帧是 0.32 秒。0.15 秒可作为节奏示意，落实剪辑时需声明取整及总时长调整。不要把实际设备是否支持某快门角与数学换算混为一谈。

长曝光时想保持主体相对清晰，需说明主体在曝光期相对画面位移较小，或摄影机追随其运动等条件。静止人物遇到任意相机横移也会模糊；选择固定机位＋运动前景，是另一种效果，不应偷换用户原意。

## 色彩流程与名称

- ALEXA 35 的官方资料列出 LogC4 和 ARRI Wide Gamut 4；Log 编码不是最终观看风格。提示词要描述完成画面的黑位、高光和色彩，不让“Log”与“未转换的灰平画面”混为一谈。[ARRI 官方](https://www.arri.com/en/camera-systems/cameras/alexa-35)
- Cooke S4/i 官方焦段表包含样本中的 25、32、40、50、65、75、100mm，系列光圈范围标为 T2–T22。它只是所选预设，不是必须使用的器材；实际传感器覆盖与拍摄模式还需另查。[Cooke 官方](https://cookeoptics.com/lens/s4-i-prime/)
- 250D 5207／7207 和 500T 5219／7219 是负片，2383／3383 是印片。区分负片创作参考与印片完成风格，不把 2383 当拍摄负片。[Kodak 250D](https://www.kodak.com/en/motion/product/camera-films/250d-5207-7207/) · [Kodak 500T](https://www.kodak.com/en/motion/product/camera-films/500t-5219-7219) · [Kodak 2383](https://www.kodak.com/en/motion/product/post/print-films/vision-color-2383-3383/)

以上链接仅支持器材和流程名词，不证明“写入这些词就能得到真实电影机影像”。新设备、具体拍摄兼容性和当前模型能力，使用时查询相应官方资料；不按旧预设推断。
