# 游戏场景参考分析

这是主 Skill 中的参考研究方法与案例底稿。用户要求研究游戏壁纸、截图、某款游戏构图，或要求基于指定作品设计时，使用此处的方法；目标是学习空间、观看路径和光影的设计方法，不复刻具体画面。提炼出的机制进入同一套世界推导与场景生成流程。

## 取样与判断

- 优先看官方游戏截图、实机画面和场景图；壁纸网站用于发现样本，须区分游戏截图、设定原画、宣传海报和玩家二次创作。
- 只选环境本身有表现力的画面。若原图有人物，把人物当作原作中的构图信息或尺度参照；迁移到本 Skill 的纯场景 Prompt 时去掉人物、NPC和角色剪影。
- 每个判断分三层：**画面可见什么**、**为什么可能有效**、**能转化成什么新的空间／摄影选择**。观察与推断不要混写。
- 少量公开图只能说明设计样本，不能证明玩家偏好或壁纸留存原因。没有可靠热度数据时，不把“受欢迎”写成结论。
- 不照搬角色、标志性道具、建筑轮廓、整套配色或完整构图；提取遮挡、动线、视点、明暗关系等可迁移机制。

## 四款游戏的可迁移特征

| 游戏 | 画面观察 | 可迁移的设计方法 | 使用边界 |
|---|---|---|---|
| **《黑神话：悟空》** | 官方景观截图把崎岖地形、旧建筑和通行路径放在同一关系里；暗色近处常把视线收向较亮、较远的空间。[PlayStation 官方截图页](https://www.playstation.com/zh-hans-cn/games/black-myth-wukong/) | 让地貌先决定观看方向，建筑作为人类活动或信仰留下的痕迹；可用崖壁、洞口、残墙遮住部分远景，只露出一段可走的路。 | 不把每张图都做成大寺庙、山谷、雾气和远景；游戏里的宏大场面只是尺度选项之一。 |
| **《影之刃零》** | 庞镇实机以雨湿街面、紧凑街屋和逐渐隐入远处的道路建立可走的空间；木桥画面用桥面纹理把视线带向未完全交代的远端。[S-GAME 庞镇演示](https://pbz.s-game.com/en-US/news/return-to-pangzhen-rtx-reveal/)、[PlayStation 官方截图页](https://www.playstation.com/zh-hant-hk/games/phantom-blade-zero/) | 把摄影机放在路、桥、门槛等真实通行位置；让地面材质和一处局部光成为视线引导，远端保留一点未知。 | 雨是庞镇的场景条件，不是所有武侠场景的默认滤镜；避免把每个地方都做成阴冷窄巷。 |
| **《燕云十六声》** | 官方资料展示了渡口、城市街道、荒漠、雪岭、草原等地域差异；隐藏山的机关与水力设施被描述为日常生产和交通的一部分，光线、雾和风随环境变化。[官方开发者信：隐藏山](https://www.wherewindsmeetgame.com/news/official/719devletter.html)、[官方开发者信：通往天空](https://www.wherewindsmeetgame.com/news/official/821devletter.html) | 先由地域和生活方式决定场景，再让设施、材料和路径说明这里如何运作。需要层次时用平台、遮挡、光线和纵深表达，不必把每处扩成巨型多层建筑。 | 不把机关、齿轮或垂直巨构变成整款游戏的统一模板；每张只取符合当地逻辑的部分。 |
| **《永劫无间》** | 官方场景原画与实机对照中，祠堂用悬挂物与明暗关系形成异样焦点；城镇高低差服务于可穿行和对抗。官方截图活动也鼓励从屋顶、山丘、树上等高处取景。[官方场景原画与实机对照](https://www.narakathegame.com/news/official/20200401/32319_872674.html)、[官方高处截图活动](https://www.narakathegame.com/news/official/20210615/32172_953792.html) | 为每处选择一个有空间意义的高点、落差或视线缺口；用单一强烈的环境关系制造记忆点，同时让通路仍然读得清。 | 角色海报、战斗特效和竞技地图的复杂路线不能直接套进纯场景；高低差只在确实服务空间时使用。 |

### 壁纸来源边界

本轮以官方游戏截图、场景图和开发者资料为判断依据。第三方壁纸站可用来发现图像样本，例如[黑神话壁纸索引](https://www.wallcoo.com/albums/black-myth-wukong-official-concept-art-and-in-game-wallpapers/)和[《燕云十六声》4K壁纸页](https://alphacoders.com/where-winds-meet-4k-wallpapers)，但其中可能混有玩家截图、二次创作、设定图和角色海报，需逐张辨别来源与类型；浏览量、收藏数只代表该站的局部数据。《永劫无间》[官方媒体库](https://www.narakathegame.com/media/)同时收录壁纸和截图，其中角色宣传图不作为纯场景模板。《影之刃零》优先参考官方已经公开的场景实机与预览图，后续可随着正式发售补入玩家壁纸样本。

## 跨作品提炼

- **先决定观看动作**：穿过、越过、窥入、下望、回望或停步，再据此选机位；不要默认正面平视、完整展示。
- **让路成为构图**：桥板、巷道、廊下、坡道、河岸或门洞只选一种主要引导关系，远端可以隐去一部分。
- **用一个关系代替元素堆砌**：例如亮窗与暗室、旧建筑与新侵蚀、窄路与空地、近处遮挡与远处留白。不要把多种东方符号并排当成意境。
- **光线指定视觉落点**：说清哪一小块受光、哪里沉入暗部、视线停在哪里；天气应改变材质或能见度，不是自动加雾加雨。
- **壁纸感来自画面组织**：主体可以偏置、被截断或局部显露；留出可呼吸的空间，让环境自身成为主体。它不等于超广角或宏大场景。
- 每批 Prompt 只借用一两种可迁移机制，并改变场景用途、尺度和机位。参考游戏的辨识性标志不能成为批量复用的模板。

## 在场景流程中的调用

用户可直接说：“参考《黑神话》的空间遮蔽来设计新场景，不要复刻原图”，或“对比《影之刃零》和《燕云十六声》的场景构图，再给我纯场景 Prompt”。先说明观察到的画面关系与可迁移机制，再进入原创世界和场景设计。若请求只生成未指定作品参考的场景，继续主 Skill 的其他步骤即可。

样本链接仅用于分析与核对。官方媒体页可能同时包含游戏截图、角色宣传图和设定原画，使用时以具体样本类型为准。
