# 东方武侠游戏场景灵感库

本库根据用户提供的 186 张场景参考图归纳。样本包含实机截图、概念图和图集拼版；只提炼场景生成与观看方法，不复刻具体作品的地标、轮廓、色彩或完整构图。它用于拓宽联想范围，不是每次必走的场景清单。

## 相关游戏参考组给出的启发

这些是本文件夹中可见样本的局部观察，不代表对整款游戏风格的完整结论：

- **《黑神话：悟空》相关图组：** 雪地寺院、洞窟祭坛、旧殿和山路常与岩壁、古树、冰湖或瀑布紧密相连；可借鉴建筑如何被地形围住、切开或遮蔽，以及入口如何把视线从近处暗部引向亮处。
- **《永劫无间》相关图组：** 场景跨越湿地、船坟、山地和聚落；栈道、水车、船体、平台等设施能说明地形如何被生活和通行利用。可借鉴区域差异与实用结构的结合，避免全世界都由寺庙、宫殿组成。
- **《燕云十六声》相关图组：** 城镇街巷和楼阁室内占有明显比重，门洞、内院、楼层和侧室构成连贯视线；室内装饰与家具也能区分经营、会客和居住空间。可借鉴城市生活空间的细分，让小场景本身有明确用途和视觉中心。

## 世界条件如何长出新场景

- **湿地／沼泽：** 先考虑水上通行、抬高的房基、木栈道、储存和捕鱼空间；避免只写“竹林加雾”。
- **崖地／高山：** 先考虑绕行、攀登、桥、栈道、避风和补给点；悬空建筑必须有可理解的支撑或连接。
- **雪地／冰湖：** 让积雪、封冻、风口和结冰改变门路、屋顶、渡口或寺院的使用状态，不只把常规建筑换成白色。
- **河港／海岸：** 让水位、潮汐、船只和装卸决定建筑朝向与岸线设施；可由废船、栈桥、闸门和货栈推导不同地点。
- **荒漠／边镇：** 让遮阴、取水、储水、驮运和风沙成为空间的核心条件；可从井、棚市、驿站、夯土巷、绿洲边界发展场景。
- **城市／商业区：** 从店铺的经营功能、街巷连接、楼上楼下关系和夜间照明入手；市井画面不必每张都表现整条街。

每个场景只取与当前世界相关的条件。把“空间用途 + 一种地形／天气／建筑状态”组合成新画面，再独立决定主体、镜头、构图、氛围和光影。纯场景输出不生成人物；人物参考只用于理解原图尺度和空间用途。
