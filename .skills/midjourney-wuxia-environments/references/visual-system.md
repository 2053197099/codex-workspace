# 场景推导与摄影选择

这是主 Skill 内的场景设计参考，用于从主题种子推导地点，并为每处空间选择有差异的镜头、构图、光影和叙事关系。它提供判断维度，不是固定提示词配方或场景清单。

## 从主题种子推导场景

先分清用户是在指定“这张就画什么”，还是给几个词让你据此构建世界。后者应把词语转成世界线索：它暗示怎样的地理、生活、交通、材料或习俗？选少数会改变场景的因果，再从中推出不同功能的独立地点；不要把种子里的物件复制到每组，也不要为了凑多样性跳到与世界无关的地点。只有题材需要时才设定神异边界，不写完整历史。

例如“竹林、棋盘，构建世界观和场景”是灵感种子：一组可直接呈现竹林中的棋局，其余场景应来自同一地域的生活与空间生态，不必再放棋盘；若用户说“每个场景都要有棋盘”，才逐组保留它。

可从不同功能取独立地点：

- 行旅与交易：客栈桌、驮车棚、渡口、驿路厨房。
- 手艺与知识：摊卷的案桌、药铺、纸坊、铁匠铺、藏历室。
- 居住与信仰：灶间、院角、村巷、小佛殿、道观内室。
- 通行与探秘：崖壁木桥、山门、巷口、洞窟、地宫入口。
- 自然地貌：河滩、雪岭、峡谷、林道、荒漠；不必附加建筑。

物件按地点用途取 1–3 个；相同世界可有不同建材、生活状态和神异浓度，不强制每处复用同一组标志物，也不把地点排成路线。

## 为每个地点单独找画面

- **镜头**：写明景别、摄影机站位／高度和朝向角度。例如“中近景，机位在桌面高度，从门外斜看室内”；单写“低机位”“透过门看”不够明确。尺度与机位分别选择，不默认大全景。
- **构图**：从空间边界、通行方向、遮挡物或空缺推导一种主关系，如偏心、框景、局部裁切、斜线、纵深或留白。
- **光影**：按开口、天气和材质决定光从哪里来、照亮什么、其余区域如何退暗；明确一个视觉落点，避免全场均匀明亮。
- **意境与叙事**：选择藏露、虚实、疏密、远近、动静、明暗之一作为可见关系；通过时间、天气、磨损或空间空缺引发联想，不靠剧情道具说明来龙去脉。

完成一组后比较地点功能、景别、机位、构图与亮暗。若几张图只换了道具，重选其中一项；不用为差异而堆更多建筑或元素。
