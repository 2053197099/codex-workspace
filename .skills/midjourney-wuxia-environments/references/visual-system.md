# 场景推导与摄影选择

本参考用于快速从题材选出有辨识度的东方武侠／神话游戏场景，并为每张画面挑镜头、构图、氛围和光影。生成结果优先清楚、简洁、可直接交给 Midjourney。

常规生成不因联想不足而加载场景灵感库：先从用户主题推导功能、生活或通行相关的地点；若空间关系或物件用途仍不确定，就删去推测细节。只有用户明确要求拓展参考范围时，才查阅[场景灵感库](scene-library.md)，且不照搬其中的地点组合或物件。

## 尺度与镜头

尺度与机位分开选择。近景／局部可聚焦门窗、桌案、祭坛、炉口等主体；中景适合室内、街巷、庭院和通路；远景用于聚落、地貌或明显尺度关系。每批以近景和中景为主，按主题加入少量远景，不默认全景。

- **机位：** 低／高机位、俯／仰、侧视、斜看、窥视、从门窗内外看。用最短词组说明观看角度；避免默认平视广角。
- **构图：** 每条只强调一个主关系：偏心、框中框、前景遮挡、对角线、纵深、留白、局部截取、边缘主体或不完整展示。不默认中轴对称、完整展示建筑。
- **光影：** 点出主要光感，如局部受光、侧逆光、冷暖对比、雾中光、雨天漫射、明暗切割；保留一个视觉落点，不逐项安排光源。
- **氛围：** 用少量词概括，由空间、天气、时间或光线支撑。不要每张都加雾、雨、冷色或“宏大震撼”。

## 东方意境与环境叙事

将藏露、虚实、疏密、远近、动静、明暗和观看路径变成可见构图关系，每张选一两种。环境叙事来自空间状态、时间、天气、使用痕迹、自然侵蚀或空缺；避免用断剑、冷茶、脚印等道具直说剧情。

游戏 CG 的完成感由有意图的镜头、构图、光影和可信空间共同形成。不要靠 `epic`、`AAA`、`monumental`、`highly detailed` 或额外堆叠建筑来代替画面设计。
