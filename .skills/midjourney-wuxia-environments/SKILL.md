# 东方武侠游戏场景

为东方武侠／神话游戏设计可探索、有环境叙事的纯场景画面。默认无人、无 NPC、无角色剪影；场景自身承担主体和尺度表达。

## 工作流程

1. **识别任务。** 区分参考分析、世界观推导、场景生成或组合任务。分析参考时使用[游戏场景参考分析](references/game-reference-study.md)，只提炼可迁移的构图与场景方法，不复刻角色、标志性道具或整套画面。
2. **建立世界底板。** 区分用户指定必须出现的内容与联想种子。沿用已有设定；没有时，从题材的地理、生活、营生和空间功能中选少数因果建立可信世界。种子启发整批场景，不自动成为每条重复道具。用户要求展示世界观时，用 2–4 条短句说明。
3. **挑选场景。** 默认生成 5 组，按用户指定数量调整。每组先确定明确地点和用途，再从[场景灵感库](references/scene-library.md)拓展空间生态；按主题从室内、街巷、生产、通行、聚落和自然环境中取舍，不填清单。以近景、中景和小空间为常见尺度，少量远景用于变化；主题确需宏大场面时再扩大。
4. **为场景找镜头。** 每条分别选择景别／机位、一个主要构图关系、氛围和光影，按[摄影选择参考](references/visual-system.md)变化视角与画面组织。避免默认正面、平视、对称和完整展示；用遮挡、明暗和纵深制造层次，不靠增加建筑楼层。
5. **写提示词并自检。** Midjourney 提示词默认用英文一行，按“主体 + 场景 + 镜头 + 构图 + 氛围 + 光影 + 限制词”组织；世界观说明和场景标题仍用中文。保留能提升主体识别、画面构成或气氛的词；删除解释、重复形容、无关道具和过度规定空间细节。用户指定其他语言时再调整。

## 提示词规则

- **主体与场景：** 明确画面核心和具体地点。地点必须有足够的识别要素；不要用泛泛的“古寺”“客栈”标题代替画面内容。只选对识别场景确有帮助的建筑特征、设施或物件，不为了显得生活化而添摆设。
- **镜头、构图、氛围、光影：** 每条都要有，写简洁、彼此配合。只选一个主要构图关系和一个清晰光影重点；不必指定摄影机周围每件物体的位置或逐一安排光源。
- **限制词：** 每条用简短、相关的限制词。默认排除人物、现代元素、卡通感、塑料质感、文字和水印；按画面需要再补模糊、过曝、平面照明等。不要机械重复长串负面词。
- “电影概念艺术”“游戏 CG”等风格词可按需少量使用，不作为每条必加词；避免机械添加 `epic`、`AAA`、`monumental`、`highly detailed` 等容易放大场景的词。
- Prompt 中不加固定室内／室外前缀；在场景描述中自然说明空间类型。避免把单个房间写成建筑群，也避免反复加楼梯、平台、屋顶制造层次。

## 世界观与东方意境

世界观用于推导地点差异与共享的材料、气候、营生，不要求每条重复设定解释。种子可以是起点，不等于每张都出现的主题物件。各场景可以独立，不强行编成路线或剧情。

把东方意境落实为画面关系：藏露、虚实、疏密、远近、动静、明暗、尺度、观看路径。每张挑一两种关系即可；不靠飞檐、灯笼、桃花、仙雾等符号堆叠制造东方感。环境叙事优先来自空间、天气、时间、使用状态和自然侵蚀，不靠断剑、冷茶、脚印等直白剧情道具。

## 出稿自检

- 主体和地点是否一眼可辨，场景该有的核心要素是否出现？
- 镜头、构图、氛围、光影是否都明确且彼此配合？
- 每个修饰词或物件是否确实提升画面？删去后若不影响主体、构图或气氛，就删。
- 是否出现建筑关系混乱、无关场景跳转或为了丰富而堆叠道具？
- 是否无人、无现代元素，限制词是否精简且针对本图？
- 一批是否超出“古建筑 + 山 + 雾”，包含符合主题的生活、生产、通行或室内空间？场景、景别、机位、构图或光影是否有变化？
