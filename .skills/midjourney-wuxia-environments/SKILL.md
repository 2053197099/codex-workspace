# 东方武侠游戏场景

这是一个完整的场景设计 Skill，涵盖游戏参考分析、世界底板、场景选择、摄影设计、Prompt 编写和出稿自检。根据用户任务走对应步骤；分析、推导和生成属于同一套方法，不是不同等级或不同版本。

目标是让画面像真实可探索的东方武侠／神话游戏空间，并把摄影机放在有意味的位置。场景本身是主体；默认无人、无 NPC、无角色剪影。

## 工作流程

1. **识别任务。** 分清用户要分析参考、生成场景，还是分析后生成。分析游戏参考时，按[游戏场景参考分析](references/game-reference-study.md)区分画面观察、设计推断和可迁移方法；生成时继续以下步骤。合并任务先提炼方法，再用于原创场景，不复刻角色、标志性道具、建筑轮廓或整套构图。
2. **理解输入。** 明确区分必须出现的地点／物件与用于联想的主题种子。明确要求的内容放进对应画面；种子用于推导世界，不自动成为每组重复的道具。沿用已有世界观；没有时从地理气候、生活谋生、交通、工艺或习俗中选少数因果建立世界底板。用户要求时以 2–4 条短句呈现，不写无关编年史。
3. **选择场景。** 默认生成 5 组；用户要求数量时照数生成，通常每批 5–10 组。题材须由世界底板推演，场景可彼此独立，不强行串路线或剧情。让地点功能、空间尺度和观看方式有变化；不要为了“丰富”而跳到无关地点。用[场景推导与摄影选择](references/visual-system.md)检查场景覆盖和差异。
4. **先定空间，再摆锚点。** 每条英文 Prompt 必须以 `Interior —`、`Exterior —` 或 `Semi-interior —` 开头。室内可透过门窗看见外部，但画面主要空间仍是室内；只有屋檐、门廊、亭子等过渡边界主导画面时才用半室内。先保证 `simple believable spatial structure`，再选 1–3 个说明地点用途的陈设或环境锚点。
5. **设计镜头和画面。** 每条都要明确景别、摄影机位置／高度、朝向／角度、主要构图关系、亮区／暗部／视线落点和氛围。镜头与构图从场景自身推导，不默认平视、广角、正面、居中或完整展示。层次主要来自前中后景、遮挡、框景、光影和消失空间，不靠增加建筑楼层。
6. **写 Prompt 并自检。** 用户要求世界观时先输出精炼世界底板，再给场景标题和可复制英文 Prompt；否则不额外展示设定。每条保留摄影信息，删去无助于空间、用途、画面或氛围的堆叠形容与物件；通常控制在约 45–70 词，必要时为表达清楚略作调整。出稿前逐条执行自检。

## 场景尺度

尺度是每组的主动选择，不是默认远景。可选近景／局部、中近景、中景、远景；尺度与机位分别决定。单批多场景时优先兼有小空间、局部空间和较大环境，只有主题需要时才用大场景。窗边、桌案、药房、客栈一角、门洞、回廊、庭院、崖桥、渡口、巷道、古道、洞窟入口和山水地貌都可成为完整画面。

## 摄影设计变量

- **镜头／机位：** 贴近主体、桌面高度、贴地、低机位、高机位、俯视、仰视、侧视、斜向观察、门洞窥视、窗内向外、室外向内、局部特写。必须说明摄影机在哪里、看向哪里；避免只报角度名词。
- **构图：** 偏心、框中框、前景遮挡、对角线、纵深引导、大面积留白、层叠空间、极简、局部截取、边缘主体、不完整展示。每张以一个主要构图关系为主，避免套用中轴对称和左右建筑夹景。
- **光影：** 根据开口、天气、时辰和材质选择侧光、逆光、漏光、天光、暮光、雨天漫射光、雾中光或明暗切割。指出受光区域、退暗区域和视线最终停留处；让光参与构图，不逐盏罗列光源，也不让全场平均漂亮。
- **氛围：** 从空间状态、时间、天气、材质状态和可见度中选取。让氛围服务地点与观看方式，不给每张图统一套雾、雨、冷色或戏剧光。

## 东方意境与环境叙事

把意境落实成可见关系：藏与露可由门窗、转角或遮挡完成；虚与实可由亮暗和虚焦空间形成；疏与密可由陈设和留白对比；远与近可由尺度和透视组织；动与静可由风、雨、水、帘影与静止建筑形成；观看路径可由道路、桥面、廊道或视线缺口引导。每张选择一两种关系即可，不把飞檐、灯笼、桃花、仙雾等符号堆在一起代替意境。

环境叙事从空间如何被使用、搁置或侵蚀中生长：磨损、修补、季节、潮湿、积尘、风化、久闭的空间、留下的空位或被遮断的路径都能让人联想。除非用户明确要求，不用断剑、冷茶、脚印等剧情符号替画面解释发生过什么。

## 硬约束与变量

**硬约束**

- 默认纯场景：无人、无 NPC、无角色剪影，不依赖人物表达尺度。
- Prompt 首句先标空间属性，室内／室外边界清晰，透视与建筑用途可信。
- 每条包含镜头、构图、光影和氛围；不能为了短而删掉摄影设计。
- 用户明确指定的场景与物件必须出现；灵感种子无需逐组照搬。
- 保持结构简明；视觉层次不等于建筑层数。

**变量**

场景尺度、空间类型、地点用途、陈设锚点、机位、景别、构图、天气、时辰、材质状态、光色与氛围按每张画面重新选择。同一批应有视觉差异，但不为差异堆砌元素。避免机械添加 `epic`、`AAA`、`monumental`、`highly detailed`、`cinematic game environment` 等容易诱发宏大模板的词。

## 出稿自检

- 是否把主题种子误写成每组必备道具，或把未指定的小灵感变成主画面？
- 这是什么空间，摄影机实际站在哪里、朝哪里看？
- 建筑、通道、楼梯与书架等是否处于合理位置，空间是否被无端扩建？
- 构图是否有明确取舍，是否只是正面展示完整建筑？
- 光照是否指出亮处、暗部和视觉落点？氛围是否有空间依据？
- 环境叙事是否来自地点状态，而非直白剧情道具？
- 一批之中是否改变了地点功能、尺度或摄影关系，而非只替换摆设？
