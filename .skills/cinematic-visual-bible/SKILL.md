# 电影视觉设定总控

## 范围与输入

识别本次交付：完整视觉设定、仅摄影质感、空间故事、逐镜分镜或局部修订。保留用户指定的章节、语言、媒介、画幅、时长与人物；不默认15秒、9:16、慢动作或无配乐。

实际查看参考图，分清角色、场景与风格职责。内部简报 `brief_lock` 只记录创作意图、参考锚点、用户固定项、本次设计和关键缺项，不要求填满工作表。单图不能证明原拍摄参数或完整建筑布局。未见身份图时保留待绑定项，继续完成其余方案，不将预设人物写入正文。

仅核心主体、交付范围或用户固定项冲突导致方案无法成立时提问。非关键创作空白直接定案；新增空间和造型明确属于本次设计，不逐项征求确认。

## 按需调用

- [空间美术](../cinematic-space-design/SKILL.md)：节点、路线、层次、材质及空间锚点。
- [摄影色彩](../cinematic-look-design/SKILL.md)：视角、景深、光源、色彩、成像及技术依据。
- [动作与镜头](../cinematic-sequence-design/SKILL.md)：人物目的、动作段落、观看视点、运镜与状态衔接。

完整方案先有空间骨架，再协调光线与动作；模块只传递已确定的关系，不各自重复整份简报。局部任务只读相关模块。工作卡是内部组织方式，不是必须生成的文件或最终表格；无需启动多个代理。

用户明确点名“随风／观山”或要求对应样本时，才读[预设](references/presets.md)。它们是项目配置，不能覆盖当前用户要求。仅复用样本框架时不加载设备、人物、色彩和节奏配置。研究原框架时说明属于功能复刻，无法证明原作者真实调用流程。

## 最终交付

完整版本默认采用下列章节；用户另有模板时以用户为准。只要摄影、单图或局部修订时不强加全版。

| 章节 | 独立职责 |
| --- | --- |
| 题目 | 概括本次主题，不堆风格标签 |
| 【通用画面质感与电影摄影参数】 | 总体成像、镜头分工、清晰层级、时间成像与光学边界；不写具体剧情 |
| 【场景设计布局】 | 核心场景与相邻节点如何连通，层次、材质、疏密和行动空间 |
| 【胶片色彩】 | 有依据的片种参考与对象配色、亮度和饱和度关系，区分产品事实与调色设计 |
| 【光线与环境氛围】 | 光从哪里来，照亮什么，如何形成明暗节奏与环境变化 |
| 【构图运镜要求】 | 人物尺度、观看视点、运动目的；完整故事在此串联镜头段落与转场 |
| 【人物造型与动作姿态】 | 身份、必要造型、人物目的、表演方式及关键接触动作 |
| 【风格及情绪基调】 | 简述整段体验和情绪变化，不复述摄影形容词 |
| 【全组统一场景细节与连续性】 | 容易漂移的身份、空间和道具锚点，以及动作引起的状态变化 |

完整故事或游览应包含“空间连接 → 人物目的 → 场景动作 → 观看视点 → 转场依据”。参考图是核心节点，允许设计相邻空间；单图复刻或指定房间边界则不扩展。未给片长仍交付不标秒数的行动段落。不要用同一姿态换景别代替故事，也不把楼梯、撩发、回眸固定套给所有作品。

## 汇编审核

1. **定案**：正文写选定方案，参数范围绑定用途，不写未取舍的候选菜单。创作决定不冒充原图事实或已验证效果。
2. **信息增量**：一句话删掉后不影响主题、画面关系、选型或效果边界就删；跨章重复合并。概括整体气质，详细写决定差异的空间、光影、景深与动作关系。
3. **相容**：机位有空间，光源有来处，关键动作可读；景深、遮挡、扩散不能共同吞没信息。具体技术检查交给摄影模块，不重复审核同一公式。
4. **连续**：人物路线可走通，视线与切镜有对应，道具状态可追踪；允许有明确目的的跳切、时空变化。
5. **交付**：直接交付成品；内部审核、常规拍摄操作、历史修订过程和未请求的后续建议不进入正文。来源及影响使用的缺项简写在正文外，不附常规免责段落。

只修自身建议的冲突，不静默改用户固定项。不声称已生成或验证真实画面。用户要求自检时先修本次成品，再将可迁移的问题写回其责任模块，不积累案例专属禁令。

## 可选下游与维护

单镜头细化可按需读取已安装的 `cinematic-shot-planner`；用户要适配平台的视频提示词时再读 `narrative-video-prompt` 并核对语言、时长边界。二者不是本套前置依赖，不因调用改变交付范围。

仅维护流程时读取[回归案例](references/validation-cases.md)，普通创作不加载测试或历史报告。模块缺失时说明实际缺项，完成可做部分，不声称执行过缺失模块。
